월간 달력

구글 캘린더 연결

연결하면 앱을 여는 동안 구글 캘린더의 일정을 몇 분마다 자동으로 가져와 달력에 표시합니다. 캘린더에서 바뀌거나 지워진 일정도 그대로 반영됩니다.

  1. 컴퓨터에서 구글 캘린더 → 오른쪽 위 ⚙ 설정
  2. 왼쪽 내 캘린더의 설정에서 공고가 들어오는 캘린더 선택
  3. 캘린더 통합의 iCal 형식의 비공개 주소를 복사해 아래에 붙여 넣기

이 주소를 아는 사람은 누구나 캘린더를 볼 수 있으니 다른 사람과 공유하지 마세요. 주소는 이 컴퓨터에만 저장되고 백업 파일에는 포함되지 않습니다.

구글 캘린더가 연결되어 있습니다. 앱을 여는 동안 5분마다, 그리고 앱으로 돌아올 때 새로 가져옵니다.

월간 달력

잡알리오 공고 받기

공공기관 채용정보(잡알리오)에서 진행 중인 공고를 받아, 고른 조건에 맞는 것만 달력에 띄웁니다. 무료이고 AI나 구글 캘린더가 필요 없어요.

  1. 공공데이터포털 · 공공기관 채용정보 조회서비스에 로그인해 활용신청
  2. 마이페이지 → 데이터 활용 → Open API → 활용신청 현황에서 일반 인증키 복사
  3. 아래에 붙여 넣고 연결 (발급 직후에는 1시간쯤 뒤부터 될 수 있어요)

인증키는 이 컴퓨터에만 저장되고 백업 파일에는 포함되지 않습니다.

항목마다 아무것도 고르지 않으면 전부 포함해요. 여러 개를 고르면 그중 하나라도 맞는 공고가 떠요.
