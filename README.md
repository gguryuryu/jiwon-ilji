# 지원일지

내 컴퓨터에서만 쓰는 취업 준비 기록 앱입니다. 지원 현황, 자소서·면접 준비, 경험 정리, 목표·자격, 공부 기록, 월간 달력을 한곳에서 봅니다.
기록은 모두 내 컴퓨터의 `data` 폴더에만 저장되고, 어디에도 올라가지 않습니다.

## 처음 설치하기 (한 번만)

### 1. Node.js 설치
[nodejs.org](https://nodejs.org)에서 **LTS** 버전(22 이상)을 받아 설치합니다. 설치 화면은 모두 기본값으로 넘기면 됩니다.

### 2. 앱 받기
공개 저장소라서 GitHub 로그인 없이 받을 수 있습니다. 셋 중 편한 방법으로 받으세요.

- **ZIP으로 받기 (가장 간단, Git 필요 없음)**: [저장소 페이지](https://github.com/gguryuryu/jiwon-ilji)에서 초록색 **Code → Download ZIP** → 원하는 곳에 압축 풀기
- **GitHub Desktop**: [desktop.github.com](https://desktop.github.com)을 설치 → File → Clone repository → URL 탭에 `https://github.com/gguryuryu/jiwon-ilji.git` 입력 → Clone
- **git 명령어**: `git clone https://github.com/gguryuryu/jiwon-ilji.git`

### 3. 실행
| | 실행 방법 |
|---|---|
| **윈도우** | 받은 폴더의 `windows-app.bat`을 **한 번** 실행하면 바탕화면과 시작 메뉴에 **지원일지 아이콘**이 생깁니다. 아이콘을 누르면 지원일지가 독립된 앱 창으로 열리고, **창을 닫으면 앱도 꺼집니다.** 시작 메뉴에서 우클릭 → 작업 표시줄에 고정해 두면 편합니다. (아이콘 없이 쓰려면 `start.bat` — 검은 창을 닫을 때까지 켜져 있습니다) |
| **맥** | 받은 폴더에 들어 있는 **`지원일지.app`**을 Dock에 끌어다 두고 누르면 됩니다. 브라우저 없이 **자기 창으로** 열리고, 창을 닫거나 ⌘Q로 끝내면 저장을 마치고 꺼집니다. (앱은 폴더 안에 둔 채로 쓰세요. 다른 곳으로 옮기면 처음에 지원일지 폴더를 한 번 골라 달라고 합니다. 아이콘 없이 쓰려면 `start.command`) |

- 앱 주소는 `http://127.0.0.1:4173` 입니다(앱이 켜져 있을 때만 열립니다).
- 윈도우에서 앱 폴더를 다른 곳으로 옮겼다면 `windows-app.bat`을 다시 실행해 아이콘을 새로 만들어 주세요.
- 처음 실행할 때 윈도우가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 눌러 주세요. 맥에서 "열 수 없다"고 막으면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 한 번 눌러 주세요(GitHub Desktop으로 받으면 보통 뜨지 않습니다).

## 업데이트 받기
왼쪽 아래 **업데이트**를 누르면 작성 중인 내용을 저장한 뒤 GitHub에서 새 버전을 가져옵니다. 업데이트를 받은 뒤 앱을 껐다 켜면 적용됩니다. 공개 저장소라 로그인은 필요 없습니다.

- **ZIP으로 받았거나 Git이 없는 컴퓨터**: GitHub에서 최신 코드 압축 파일을 받아 앱 파일만 바꿉니다. 받은 버전은 `.app-version.json`에 적어 두고, 새 버전에서 빠진 앱 파일은 지웁니다. 앱 코드를 직접 고쳤다면 그 수정은 새 버전으로 덮어써집니다(직접 만든 새 파일은 그대로 둡니다).
- **Git으로 받은 폴더**: `git fetch` 뒤 빨리 감기로만 반영합니다(병합 커밋을 만들지 않음). 컴퓨터에 Git이 있으면 되고, GitHub Desktop을 설치했다면 그 안에 든 Git을 찾아 씁니다. 앱 코드 파일을 수정했다면 덮어쓰지 않고 안내합니다. PR용 브랜치가 GitHub에서 지워졌으면, 내용이 이미 main에 합쳐진 경우에만 main으로 옮겨서 받습니다.
- 버튼 대신 GitHub Desktop의 **Fetch origin → Pull origin**이나 `git pull`로 직접 업데이트해도 됩니다.

업데이트 버튼이 없거나 예전 버전에서 버튼이 실패하면, 한 번만 위 방법(또는 ZIP 새로 받기)으로 직접 받은 뒤 앱을 다시 켜 주세요.
내 기록(`data` 폴더)은 업데이트해도 그대로 남습니다.

## 내 기록과 백업
- 기록은 `data/job-search.json`에 자동 저장됩니다. 이 폴더는 GitHub에 절대 올라가지 않습니다.
- 왼쪽 아래 **백업**을 누르면 기록 전체를 파일 하나로 내려받고, **복원**으로 되돌릴 수 있습니다. 가끔 백업해 두세요.
- 처음에는 비어 있습니다. 지원 현황의 **예시 살펴보기**를 누르면 예시 공고가 들어가고, 언제든 지울 수 있습니다.

## 선택 기능
- **구글 캘린더 연결**: 월간 달력의 **구글 캘린더 연결**에서 캘린더의 "iCal 형식의 비공개 주소"를 넣으면, 앱이 켜져 있는 동안 몇 분마다 일정을 가져옵니다. 이 주소도 `data` 폴더에만 저장됩니다.

## 할 수 있는 일

- **새 공고**에서 링크 하나를 붙여 넣으면 회사·기관명, 직무, 고용형태, 마감일을 자동으로 읽습니다. 읽지 못한 항목은 그 자리에서 고칩니다.
- **지원 현황**: 진행 상태(관심 → 자소서 → 지원·서류 → 필기 → 면접 → 합격/종료)별로 묶어 표나 보드로 봅니다. 표에서 직무·상태·고용형태를 바로 고치고, 회사 이름을 누르면 오른쪽에 사이드 피크가 열립니다(Esc로 닫기, ⤢로 전체 페이지). 보드에서는 카드를 끌어 상태를 바꿉니다.
- **목표 · 자격** (지원 현황 위): 해 온 것 · 진행 중 · 남은 목표를 보드처럼 봅니다. 해 온 것에는 끝낸 목표, 자격·어학 점수, 최종 합격이 날짜순으로 쌓입니다. 목표를 다른 칸으로 끌면 완료·시작·보류로 바뀌고, 진행 중인 목표는 다음 할 일을 그 자리에서 체크합니다. 자격증 목표를 완료하면 자격으로 한 줄만 남고, 어학 성적은 유효기간 2년이 채워지며, 점수를 갱신하면 이전 점수가 기록으로 남습니다.
- **자소서**: 공고별로 문항 단위로 쓰고, 글자 수 제한과 공백 포함/제외 글자 수를 봅니다. 문항에 경험을 연결할 수 있습니다.
- **면접 준비 · 면접 후기**: 예상 질문과 답(말하는 데 걸리는 시간 표시), 자주 나오는 질문 바로 추가, 면접 후 받은 질문·분위기·아쉬운 점 기록. 받은 질문은 버튼 하나로 면접 준비에 옮깁니다.
- **공부 기록**: 반복할 공부를 루틴으로 정하고(이름·구분·요일. 구분은 NCS·전공·자격증에 직접 추가도 가능, 교재를 연결하면 공부한 분량이 진도에 쌓임) 날마다 체크하면, 그날 루틴을 끝낸 비율만큼 깃허브 잔디처럼 칸이 채워집니다. 칸을 누르면 그날 기록을 보고 고칩니다. 교재 루틴은 체크 한 번이면 목표 분량으로 기록되고, 다르게 공부했으면 분량을 눌러 고칩니다. 목표 보드의 NCS·전공 목표 옆에 오늘 루틴 수가 보이고, 누르면 이 탭으로 옵니다. 구분이 자격증인 루틴은 목표 보드의 자격증 목표에 직접 이을 수 있고, 그 자격증을 완료하면 이은 루틴을 정리할지 묻습니다. 처음엔 **전산직 필기 계획으로 시작**을 누르면 민경채·응용수리·전공 이론·오답 다시 풀기·토요일 모의고사 루틴이 들어가고, 자유롭게 고치거나 지울 수 있습니다.
- **실험실**: 할 일을 파이썬처럼 `while 지하철 타는 동안:` 아래에 `영단어 외우기`, `if 밥 먹고 나면:` 아래에 `응용수리 10문제`를 적습니다. while은 ▶ run부터 break까지 도는 시간을 재고(조건에 `4`·`50분 × 2`처럼 숫자를 넣으면 집중·휴식을 번갈아 도는 뽀모도로가 되고, `15시까지`·`~18:30`처럼 시각을 넣으면 그 시각까지 남은 시간을 세다가 그 시각에 끝나며, 바뀔 때 소리와 알림이 나옵니다), if는 ▶ run할 때마다 기록됩니다. 블록 끝 주석과 아래 OUTPUT에 오늘 실행한 기록이 쌓이고, 도는 동안에는 창 제목에 남은 시간이 보입니다. 할 일 줄의 **↗ 연결**로 공부 기록 루틴이나 목표 보드의 할 일을 이으면 `routine.응용수리_20문제()`처럼 보이고, if를 실행하거나 뽀모도로를 끝까지 돌면 그쪽에도 체크됩니다(중간에 break하면 알림에서 체크할지 고릅니다).
- **경험 정리**: 경험마다 역할·키워드·상세 내용을 적고(`#`, `##`, `-` 서식), 어느 공고의 자소서·면접에 썼는지 봅니다.
- **월간 달력**: 공고 마감일과 다음 일정이 자동으로 표시되고, 아래로 내리면 다음 달이 이어집니다. 구글 캘린더 일정을 눌러 **지원 현황에 추가**할 수 있고, `.ics` 파일도 가져올 수 있습니다.

## 알아 두면 좋은 점
- 앱이 켜져 있을 때만 구글 캘린더를 새로 가져옵니다. 구글 쪽 반영에도 몇 분~몇 시간 걸릴 수 있습니다.
- 로그인이 필요하거나 화면을 자바스크립트로 그리는 공고 사이트는 일부 항목을 직접 입력해야 합니다.
- 4173번 포트를 다른 프로그램이 쓰고 있으면 실행할 때 안내가 나옵니다. 그 프로그램을 끄거나 `PORT=4180`처럼 다른 포트로 실행하세요.

## 개발 메모

```
server.mjs          앱 서버: 파일 저장(판 번호로 충돌 방지), 공고 링크 읽기, 구글 캘린더 가져오기, --open으로 브라우저 열기
lib/parse.mjs       공고 페이지·캘린더 일정에서 회사·직무·마감일을 읽는 함수(네트워크 없음)
index.html          화면 틀과 창(새 공고, 일정, 캘린더 연결)
style.css           스타일. 폭별 규칙(@media)은 파일 끝에 넓은 화면 → 좁은 화면 순서로 둔다
js/main.js          시작점: 공통 이벤트 연결, 데이터 불러오기
js/state.js         데이터와 현재 화면(다른 파일은 setData, setRoute로만 바꾼다)
js/store.js         저장·재시도·다른 창과 맞추기, merge.js는 충돌 때 변경 합치기
js/router.js        주소(#/…)와 화면 이동, 뒤로 가기
js/goals.js         지원 현황 위의 목표 · 해 온 것 보드, 목표 창, 자격 창
js/postings.js      지원 현황(표·보드·단계 요약), posting-detail.js 상세, interview.js 면접 후기, peek.js 사이드 피크, date-field.js 날짜 칸
js/lab.js           실험실(while·if 블록), 계산은 lab-model.js
js/study.js         공부 기록(잔디·루틴·교재 진도), 계산은 study-model.js(요일별 루틴·수정 이력·진도·잔디)
js/experiences.js   경험 정리, calendar.js·ics.js·event-dialog.js 달력, posting-dialog.js 새 공고 창
js/util.js, model.js, ui.js, dom.js   공통 도구, 상태 규칙, 알림·움직임, 자주 쓰는 화면 요소
지원일지.app        맥 네이티브 앱(WKWebView 창, 인텔·애플 실리콘 겸용). 소스는 mac/main.swift, 다시 만들 때는 mac/build.command
windows-app.bat     윈도우 아이콘 바로가기 만들기. start.bat · start.command는 아이콘 없이 실행
assets/             아이콘(icon.svg 원본, icon-transparent.ico), 윈도우 실행기(launch-windows.vbs: 서버를 --exit-when-closed로 켜고 Edge 앱 창으로 연다), 바로가기 만들기(make-shortcut.ps1)
fonts/              Pretendard 글꼴(SIL Open Font License, fonts/OFL.txt)
test/               자동 테스트(서버를 실제로 띄워 보는 테스트 포함)
```

테스트는 `npm test`로 돌립니다(설치할 패키지 없음). GitHub에 올릴 때마다 윈도우·맥·리눅스에서 자동으로 돌아갑니다(`.github/workflows/test.yml`).
